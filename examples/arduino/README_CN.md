## 简介

本仓库提供了 Arduino 平台与 AI 语音交互模块通信的示例代码，支持 I2C 和 UART 两种通信方式。

- **语音识别模块**：支持离线语音识别，识别后输出命令ID
- **播报功能**：支持被动播报、功能词播报、命令词播报
- **通信协议**：I2C 地址 0x2A，UART 波特率 115200

## IIC 版本使用

### 1. 打开工程

- 在 Arduino IDE 中打开 `IIC_Voice/IIC_Voice.ino`

### 2. 上传代码

- 选择正确的开发板型号（工具 → 开发板）
- 选择正确的端口号（工具 → 端口）
- 点击上传按钮（→）
- 等待上传完成

### 3. 运行测试

1. 打开串口监视器（工具 → 串口监视器）
2. 设置波特率为 **115200**
3. 正常启动后会显示：

```
IIC Voice Module Initialized
```

4. 对语音模块说出命令词，会显示对应的 ID：

```
IIC Voice Module Initialized
ID: 1
ID: 4
ID: 10
```

### 4. 代码说明

```cpp
// 初始化 I2C
IIC_Init();

// 读取命令 ID
int commandId = IIC_ReadCommand();

// 设置播报
IIC_SetCommandVoice(0x00);  // 命令词播报
```

## 常见问题

### Q1: 串口监视器没有任何输出

**A: 检查以下几点：**
- 检查串口波特率是否为 115200
- 检查是否选择了正确的端口
- 检查 TX/RX 是否接反
- 检查 GND 是否共地

### Q2: I2C 版本显示 "IIC Read Error"

**A: 检查 I2C 连接：**
- 检查 SDA/SCL 是否接反
- 检查设备地址是否正确（0x2A）
- 检查是否共地

### Q3: 命令 ID 只显示 0 或 255

**A: 正常现象：**
- 0 = 未识别到有效命令
- 255 = 无新数据
- 正常识别后才会输出有效 ID

### Q4: 识别准确率不高

**A: 优化建议：**
- 确保环境安静，背景噪音不要太大
- 离麦克风距离适中（10-50cm）
- 语速适中，发音清晰

### Q5: UART 版本接收不到数据

**A: 检查：**
- 确认语音模块 TX 接 Arduino D10 (RX)
- 确认语音模块 RX 接 Arduino D11 (TX)
- 检查波特率是否为 115200
