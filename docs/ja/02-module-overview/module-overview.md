# 製品情報

## 1. 音声対話モジュールの概要

CI1302 は、ChipIntelli（启英泰伦）が開発した新世代の高性能ニューラルネットワークインテリジェント音声チップです。ChipIntelli が独自開発したブレイン・ニューラルネットワーク・プロセッサ BNPU V3 と CPU コアを統合し、システムクロック周波数は最大 220MHz、最大 640KB の SRAM を内蔵、PMU 電源管理ユニットと RC 発振器を統合、さらに 2 チャンネルの高性能・低消費電力 Audio Codec と、UART、IIC、IIS、PWM、GPIO、PDM などの複数のペリフェラル制御インターフェースを統合しています。本チップは、抵抗やコンデンサなどのわずかな外付け部品だけで、さまざまなインテリジェント音声製品のハードウェアソリューションを実現でき、優れたコストパフォーマンスを実現します。

第 3 世代のハードウェア BNPU 技術を採用し、DNN、TDNN、RNN、CNN などのニューラルネットワークや並列ベクトル演算をサポートすることで、音声認識、声紋認識、コマンドワードの自己学習、音声検出、ディープラーニングノイズリダクションなどの機能を実現します。本チップソリューションは中国語、英語、日本語を含む複数のグローバル言語にも対応しており、家電、照明、玩具、ウェアラブルデバイス、産業、車載などの製品分野における音声対話、制御、その他各種インテリジェント音声ソリューションに幅広く適用できます。

CI1302 チップはブレイン・ニューラルネットワーク・プロセッサコア（BNPU）を備え、オフラインのニューラルネットワーク加速演算と音声信号処理ハードウェアアクセラレーションをサポートします。CPU クロックは最大 220MHz に達し、オフラインでの遠距離音声認識を実現するほか、2MB の FLASH ストレージを内蔵し、最大 300 のコマンドワードをサポートします。

## 2. 製品の特長

- 110 以上の音声コマンドをプリインストールし、中国語と英語のコマンドワードをカスタマイズ可能。

ユーザーは、提供されている Web インターフェースを通じてコマンドワードを変更し、新しいファームウェアファイルを生成して、PC ソフトウェアでモジュールに書き込むことができ、その後モジュールは新しいコマンドを認識します。内蔵の 2MB ストレージ領域は、最大約 120 のコマンドワードの書き込みをサポートします。

- 高忠実度スピーカーと高性能マイクを内蔵。

先進的なアルゴリズムと回路ノイズリダクション技術を統合し、環境の背景ノイズを効果的に除去、5 メートルの範囲内で 99% の認識率を達成し、自然な会話とエコーキャンセリングを可能にします。クリアな音声出力を提供し、音声のディテールを正確に再現します。

- オンボードのコプロセッサと IIC／シリアル／UART／Type-C インターフェース。

STC8H チップを統合し、音声データをシリアルまたは IIC データ形式に自動変換して、外部ホスト機器との通信プロセスを簡素化します。各種接続ケーブルを無償で提供し、ユーザーは MCU 開発ボードや組み込みホスト機器に接続して通信を実現し、オリジナルの DIY プロジェクトを作成できます。

- 各種開発ボードに基づく使用チュートリアルを提供。

STM32、ESP32、MSPM0、Raspberry Pi、Jetson シリーズ開発ボード、RDK などの開発ボード情報を提供します。また、ROS1 および ROS2 システム用の SDK ファイルも提供します。

## 3. 動作原理

本モジュールはキーワードウェイクアップ方式を採用しています。ユーザーはまず、あらかじめ設定されたウェイクワードを話しかけて音声対話モジュールを起動する必要があります。起動後、音声認識を実行できます。出荷時ファームウェアのデフォルトのウェイクキーワードは「你好，小犀」（こんにちは、シャオシー）です。15 秒以内に音声が検出されない場合、モジュールはスリープモードに入り、以降の使用時には再度ウェイクアップする必要があります。

CI1302 チップが対応する音声エントリーを認識すると、シリアルポートと IIC インターフェースを介してそれを送信し、あわせてフィードバック読み上げを行います。IIC チップは受信した音声コマンドを保存し、IIC スレーブプロトコルを介して送信します。

本モジュールはウェイクワードの変更、コマンドワードの変更、カスタムエントリーをサポートしています。操作方法は、チュートリアル「ウェイクワードとコマンドワードの変更」および「カスタムプロトコルエントリーの作成」で学ぶことができます。

## 4. 注意事項

1. 電源には 5V 電圧を使用してください。5V を超えるとモジュールが破損します。
2. 使用環境は静かな場所にしてください。騒がしい環境では認識性能に影響します。
3. エントリーを発話するときは、声を大きく、速すぎないようにしてください。モジュールから 5 メートル以内にいることを推奨します。

| No. | ハードウェア名         | 説明                                                                 |

| 1   | スピーカー               | アナログ信号を音に変換します                                         |

| 9   | 逆接続保護 | 5V/GND の逆接続を保護します                                 |
| 10  | IIC インターフェース         | スレーブとして電源供給およびホスト機器との通信を行います           |
| 11  | シリアルインターフェース      | 外部シリアルポートを提供。プロトコルによる読み上げ制御が可能です            |
