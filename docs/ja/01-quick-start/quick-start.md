# 3. 音声認識と読み上げ

Type-C で音声対話モジュールに電源を供給した後、「你好，小犀」（こんにちは、シャオシー）と話しかけてモジュールをウェイクアップさせます。ウェイクアップに成功すると、モジュールは「我在」（いますよ）と応答し、現在音声認識状態であることを示します。15 秒以内にコマンドエントリーが認識されない場合、モジュールはスリープモードに入り、「我去休息了」（休みに入ります）と読み上げます。再度モジュールをウェイクアップするには、もう一度ウェイクワードを話しかけるだけです。

出荷時ファームウェアにはコマンドワードと読み上げワードが組み込まれています。プロトコル一覧は付属のドキュメント資料で確認できます。以下の表は、コマンドワードと読み上げワードのプロトコル一覧の一部を抜粋したものです。機能タイプを確認することで、各コマンドワードが何を表すかを知ることができます。「受動」と記された読み上げワードは、PC のシリアルポート、マイコン、その他のホスト機器から対応するコマンドを音声対話モジュールに送信してトリガーする必要があります。詳細は以下を参照してください。

読み上げモードには、能動と受動の 2 種類があります。

能動読み上げ：表に従ってコマンドワードを話しかけると、モジュールが対応するフレーズを能動的に読み上げます。ウェイクアップ後に「小车前进」（車が前進）と言うと、モジュールは「好的，正在前进」（了解、前進しています）を能動的に読み上げます。

受動読み上げ：プロトコル表のコマンドをシリアルポート経由で音声モジュールに送信して初めて、モジュールは対応するフレーズを読み上げます。IIC プロトコルで受動読み上げレジスタに該当する読み上げデータを書き込むことでもトリガーできます。詳細は「3. マルチホスト通信」を参照してください。
