# カスタムプロトコルエントリーの作成

# 1. 音声チップファームウェアの作成

# 1.1 注意事項

本モジュールには、工場出荷時に音声認識ファームウェアが書き込み済みです。ドキュメント資料には出荷時ファームウェアも用意されています。ファームウェアを再作成する必要がある場合は、以下の手順に従ってファームウェアを作成できます。

# 1.2 ファームウェアの作成

まず、「启英泰伦语音AI平台」（ChipIntelli 音声 AI プラットフォーム）のリンクを開き、ファームウェア作成サイトにアクセスします。
メニューバーの「功能开发」（機能開発）をクリックし、次に「製品開発」セクションの下にある「离线语音识别大模型应用」（オフライン音声認識大規模モデルアプリケーション）をクリックします。

![1](../../en/04-custom-protocol/images/1.png)

ここでログインを求められます。ご自身の情報でプラットフォームのアカウントを登録する必要があります。本チュートリアルでは、あらかじめ登録済みです。ログイン後、再度「语音识别固件及SDK开发」（音声認識ファームウェアおよび SDK 開発）をクリックします。

![2](../../en/04-custom-protocol/images/2.png)

ページがリダイレクトしたら、左側の「新建项目」（新規プロジェクト）をクリックします。以下に示すように新しい製品を作成します。製品名と説明は自由に設定できます。その他の情報は、赤枠の内容に従って選択する必要があります。製品タイプは「通用->智能中控」（汎用 -> スマートセントラルコントロール）にします。完了したら「创建」（作成）をクリックします。

![3](../../en/04-custom-protocol/images/3.png)

次に、プロジェクトの基本情報を入力します。中国語の認識が必要なため、言語タイプは「中文」（中国語）を選択します。英語の認識が必要な場合は、適宜変更してください。以下のようにその他の情報を選択し、「继续」（続行）をクリックします。

![4](../../en/04-custom-protocol/images/4.png)

次に、ファームウェアを設定します。ここでは変更が必要な部分のみを説明します。アルゴリズムパラメータの下にあるエコーキャンセリングオプションを有効にします。

![5](../../en/04-custom-protocol/images/5.png)

ハードウェアパラメータで、水晶発振器のソースを「内部 RC」（内蔵 RC）に設定します。

![6](../../en/04-custom-protocol/images/6.png)

プリントシリアルポート設定で、UART0 のレベルをオープンドレイン機能に設定し、外部で 5V にプルアップできるようにします。

![7](../../en/04-custom-protocol/images/7.png)

通信シリアルポート設定を変更します。ボーレートを 115200 に設定し、UART1 のレベルをオープンドレイン機能に設定して、外部で 5V にプルアップできるようにします。設定後、「继续」（続行）をクリックして次のステップに進みます。

![8](../../en/04-custom-protocol/images/8.png)

ここでコマンドワード編集機能に入ります。まず、読み上げ音声を選択します。ここでは「小蝶-清新女声 Ver.3」（シャオディエ - フレッシュ女声 Ver.3）を選択します。

![9](../../en/04-custom-protocol/images/9.png)

次に、コマンドワードの添付ファイルをアップロードします。本ドキュメントと同じディレクトリにある「命令词播报词协议列表V1\_中文」（コマンドワード・読み上げワードプロトコル一覧 V1\_中文）の表計算ファイルを見つけ、Web ページに直接ドラッグしてアップロードします。

![10](../../en/04-custom-protocol/images/10.png)

ファイルのアップロード後、下の表でコマンドワードのデータを確認できます。

![11](../../en/04-custom-protocol/images/11.png)

自己学習機能を開き、「指定学习」（指定学習）を選択します。システムは 4 つの自己学習コマンドを自動生成します。ここでは変更を加えません。

![12](../../en/04-custom-protocol/images/12.png)

送信後、数分待つとファームウェアの作成が完了します。完了したら、「下载固件」（ファームウェアをダウンロード）をクリックして、作成されたファームウェアを取得します。

![13](../../en/04-custom-protocol/images/13.png)

ファームウェアの書き込み手順については、「4. モジュールファームウェアの書き込み方法」を参照してください。

# 2. 機能エントリーの変更

添付ファイルの「命令词播报词协议列表V1\_中文」（コマンドワード・読み上げワードプロトコル一覧 V1\_中文）ファイルを開きます。

![14](../../en/04-custom-protocol/images/14.png)

表計算ファイル内の機能エントリー（最初の 10 エントリー）を見つけます。この 10 の機能エントリーは固定エントリーであり、追加はできず、変更のみ可能であることに注意してください。

![15](../../en/04-custom-protocol/images/15.png)

ここでは、ウェイクワードの読み上げフレーズを変更する例を挙げます。「你好，小犀」を認識した後の読み上げを「在的」（いますよ）から「我在」（いますよ）に変更します。

![16](../../en/04-custom-protocol/images/16.png)

変更後に保存し、「1.2 ファームウェアの作成」の手順に従って表計算ファイルをサイトにインポートします。すでに一度ファームウェアを作成している場合は、前回のプロジェクトで「继承」（継承）ボタンをクリックすると、パラメータ設定の手順を省略できます。

![13](../../en/04-custom-protocol/images/13.png)

ファームウェアを再作成した後、音声対話モジュールにファームウェアを書き込む必要もあります。これにより、変更した機能エントリーが有効になります。

# 3. 新しいコマンドエントリーの追加

添付ファイルの「命令词播报词协议列表V1\_中文」（コマンドワード・読み上げワードプロトコル一覧 V1\_中文）ファイルを開きます。

![14](../../en/04-custom-protocol/images/14.png)

表計算ファイルの最下部に、新しいコマンドエントリーを追加します。ここでは「打扫房间」（部屋を掃除）というコマンドワードを追加する例を挙げます。

![17](../../en/04-custom-protocol/images/17.png)

ここでは、機能タイプに「命令词」（コマンドワード）を選択し、読み上げモードを「主」（能動）に設定する必要があります。これにより、「打扫房间」を認識した後、「好的」（了解）を能動的に読み上げます。

![18](../../en/04-custom-protocol/images/18.png)

次に、送信プロトコルを理解しましょう。データの 1 バイト目と 2 バイト目はデータフレームヘッダであり、変更する必要はありません。機能タイプにコマンドワードを選択した場合、送信プロトコルに従って、データの 3 バイト目は "00" でなければなりません。これは、そのコマンドが「コマンドワード」か「読み上げフレーズ」かを区別するためのものです。

![19](../../en/04-custom-protocol/images/19.png)

データの 4 バイト目はコマンドワードのデータ ID で、16 進数の値です。前のコマンドワードの ID が "8B" だったため、このバイトを "8C" に設定する必要があります。特殊なケースでは、データ ID を同じにすることもできます。たとえば、2 つのコマンドワードが返す結果が同一である場合です。

![20](../../en/04-custom-protocol/images/20.png)

プロトコルの 5 バイト目は "EE" に固定されており、これも変更する必要はありません。表計算ファイルでは、送信プロトコルと受信プロトコルを一致させる必要があります。

![21](../../en/04-custom-protocol/images/21.png)

変更後に保存し、「1.2 ファームウェアの作成」の手順に従って表計算ファイルをサイトにインポートします。すでに一度ファームウェアを作成している場合は、前回のプロジェクトで「继承」（継承）ボタンをクリックすると、パラメータ設定の手順を省略できます。

![13](../../en/04-custom-protocol/images/13.png)

ファームウェアを再作成した後、音声対話モジュールにファームウェアを書き込む必要もあります。これにより、新しいコマンドエントリーの機能が有効になります。

# 4. 新しい読み上げフレーズの追加

添付ファイルの「命令词播报词协议列表V1\_中文」（コマンドワード・読み上げワードプロトコル一覧 V1\_中文）ファイルを開きます。

![14](../../en/04-custom-protocol/images/14.png)

表計算ファイルの最下部に、新しいエントリーを追加します。ここでは「现在是晚上」（今は夜です）という読み上げフレーズを追加する例を挙げます。

![22](../../en/04-custom-protocol/images/22.png)

ここでは、機能タイプに「播报语」（読み上げフレーズ）を選択し、読み上げモードを「被」（受動）に設定する必要があります。

![23](../../en/04-custom-protocol/images/23.png)

次に、送信プロトコルを理解しましょう。データの 1 バイト目と 2 バイト目はデータフレームヘッダであり、変更する必要はありません。機能タイプに読み上げフレーズを選択した場合、送信プロトコルに従って、データの 3 バイト目は "FF" でなければなりません。これは、そのコマンドが「読み上げフレーズ」であることを区別するためのものです。

![24](../../en/04-custom-protocol/images/24.png)

データの 4 バイト目はコマンドワードのデータ ID で、16 進数の値です。前の読み上げフレーズの ID が "8B" だったため、このバイトを "8C" に設定する必要があります。

プロトコルの 5 バイト目は "EE" に固定されており、これも変更する必要はありません。表計算ファイルでは、送信プロトコルと受信プロトコルを一致させる必要があります。

![25](../../en/04-custom-protocol/images/25.png)

変更後に保存し、「1.2 ファームウェアの作成」の手順に従って表計算ファイルをサイトにインポートします。すでに一度ファームウェアを作成している場合は、前回のプロジェクトで「继承」（継承）ボタンをクリックすると、パラメータ設定の手順を省略できます。

![13](../../en/04-custom-protocol/images/13.png)

ファームウェアを再作成した後、音声対話モジュールにファームウェアを書き込む必要もあります。これにより、新しいコマンドエントリーの機能が有効になります。
