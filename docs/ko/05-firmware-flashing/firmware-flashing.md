# 1.2 플래싱 소프트웨어 열기

첨부 파일에서 음성 칩 펌웨어 플래싱 도구 폴더를 열고 "PACK\_UPDATE\_TOOL.exe"를 클릭합니다.

![2](../../en/05-firmware-flashing/images/2.png)

CI1302 칩을 선택한 다음 "固件升级"(펌웨어 업그레이드)를 클릭합니다.

![3](../../en/05-firmware-flashing/images/3.png)

펌웨어 업그레이드 인터페이스로 들어갑니다. "F1"을 누르면 도움말을 볼 수 있습니다.

방금 생성한 펌웨어를 클릭하여 선택합니다. 첨부 파일에서 출하 시 펌웨어 "CI1302中文单麦\_V00681\_UART1\_115200\_2M"을 찾습니다.

![4](../../en/05-firmware-flashing/images/4.png)

펌웨어를 선택하고 해당 시리얼 포트 번호를 찾아 체크박스를 선택합니다.

![5](../../en/05-firmware-flashing/images/5.png)

슬라이드 스위치를 "Download" 위치로 옮깁니다. "Download"는 음성 칩(즉, 오른쪽)에 펌웨어를 플래싱하는 것을 나타냅니다.

![6](../../en/05-firmware-flashing/images/6.png)

스위치를 해당 위치로 옮긴 후, 음성 상호작용 모듈의 RST 버튼을 누르면 플래싱 과정에 진입합니다. 플래싱이 성공적으로 완료될 때까지 기다린 다음 "退出"(종료)를 클릭합니다.

![7](../../en/05-firmware-flashing/images/7.png)
