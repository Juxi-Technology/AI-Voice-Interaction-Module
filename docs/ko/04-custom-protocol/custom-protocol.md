# 사용자 정의 프로토콜 항목 생성

# 1. 음성 칩 펌웨어 생성

# 1.1 주의 사항

모듈에는 출하 시 음성 인식 펌웨어가 미리 플래싱되어 있습니다. 문서 첨부 파일에도 출하 시 펌웨어가 제공됩니다. 펌웨어를 다시 만들어야 하는 경우 아래 단계에 따라 펌웨어를 생성할 수 있습니다.

# 1.2 펌웨어 생성

먼저 "启英泰伦语音AI平台"(ChipIntelli 음성 AI 플랫폼) 링크를 열어 펌웨어 생성 웹사이트에 접속합니다.
메뉴 바에서 "功能开发"(기능 개발)을 클릭한 다음, 제품 개발(Product Development) 섹션 아래의 "离线语音识别大模型应用"(오프라인 음성 인식 대형 모델 응용)을 클릭합니다.

![1](../../en/04-custom-protocol/images/1.png)

이 시점에서 로그인하라는 메시지가 표시됩니다. 본인의 정보로 플랫폼 계정을 등록해야 합니다. 이 튜토리얼에서는 미리 등록해 두었습니다. 로그인 후 "语音识别固件及SDK开发"(음성 인식 펌웨어 및 SDK 개발)을 다시 클릭합니다.

![2](../../en/04-custom-protocol/images/2.png)

페이지가 리디렉션되면 왼쪽의 "新建项目"(새 프로젝트)를 클릭합니다. 아래와 같이 새 제품을 생성하며, 제품 이름과 설명은 사용자 정의할 수 있습니다. 나머지 정보는 빨간색 테두리로 표시된 내용에 따라 선택해야 합니다. 제품 유형은 "通用->智能中控"(일반->스마트 중앙 제어)이어야 합니다. 완료 후 "创建"(생성)을 클릭합니다.

![3](../../en/04-custom-protocol/images/3.png)

다음으로 프로젝트의 기본 정보를 입력합니다. 중국어 인식이 필요하므로 언어 유형에서 "中文"(중국어)를 선택합니다. 영어 인식이 필요하면 그에 맞게 수정할 수 있습니다. 아래와 같이 기타 정보를 선택한 다음 "继续"(계속)을 클릭합니다.

![4](../../en/04-custom-protocol/images/4.png)

그런 다음 펌웨어를 구성합니다. 여기서는 수정이 필요한 부분만 설명합니다. 알고리즘 매개변수에서 에코 제거 옵션을 활성화합니다.

![5](../../en/04-custom-protocol/images/5.png)

하드웨어 매개변수에서 크리스털 발진기 소스를 "内部 RC"(내부 RC)로 설정합니다.

![6](../../en/04-custom-protocol/images/6.png)

프린트 시리얼 포트 구성에서 UART0 레벨을 오픈 드레인 기능으로 설정하여 5V로의 외부 풀업을 지원합니다.

![7](../../en/04-custom-protocol/images/7.png)

통신 시리얼 포트 구성을 수정합니다. 보드 레이트를 115200으로 설정하고 UART1 레벨을 오픈 드레인 기능으로 구성하여 5V로의 외부 풀업을 지원합니다. 구성 후 "继续"(계속)을 클릭하여 다음 단계로 진행합니다.

![8](../../en/04-custom-protocol/images/8.png)

이제 명령어 편집 기능으로 들어갑니다. 먼저 방송 음성을 선택합니다. 여기서는 "小蝶-清新女声 Ver.3"(샤오디에 - 청량한 여성 음성 Ver.3)을 선택합니다.

![9](../../en/04-custom-protocol/images/9.png)

다음으로 명령어 첨부 파일을 업로드합니다. 이 문서와 같은 디렉터리에 있는 "命令词播报词协议列表V1\_中文"(명령어/방송어 프로토콜 목록 V1\_중국어) 스프레드시트를 찾아 웹페이지로 직접 끌어다 놓아 업로드합니다.

![10](../../en/04-custom-protocol/images/10.png)

파일을 업로드한 후 아래 표에서 명령어 데이터를 볼 수 있습니다.

![11](../../en/04-custom-protocol/images/11.png)

자기 학습 기능을 열고 "指定学习"(지정 학습)을 선택합니다. 시스템이 4개의 자기 학습 명령을 자동으로 생성합니다. 여기서는 아무것도 변경하지 않습니다.

![12](../../en/04-custom-protocol/images/12.png)

제출 후 몇 분 정도 기다리면 펌웨어 생성이 완료됩니다. 완료되면 "下载固件"(펌웨어 다운로드)를 클릭하여 생성된 펌웨어를 받습니다.

![13](../../en/04-custom-protocol/images/13.png)

펌웨어 플래싱 단계는 "4. 모듈 펌웨어 플래싱 방법"을 참조하십시오.

# 2. 기능 항목 수정

첨부 파일에서 "命令词播报词协议列表V1\_中文"(명령어/방송어 프로토콜 목록 V1\_중국어) 파일을 엽니다.

![14](../../en/04-custom-protocol/images/14.png)

스프레드시트에서 기능 항목을 찾습니다. 이는 처음 10개의 항목입니다. 이 10개의 기능 항목은 고정 항목으로 추가할 수 없고 수정만 가능합니다.

![15](../../en/04-custom-protocol/images/15.png)

여기서는 웨이크 워드의 방송어를 수정하는 것을 예로 듭니다. "你好，小犀" 인식 후의 방송을 "在的"(여기 있어요)에서 "我在"(여기 있습니다)로 변경합니다.

![16](../../en/04-custom-protocol/images/16.png)

수정 후 저장한 다음 "1.2 펌웨어 생성"의 단계에 따라 스프레드시트를 웹사이트로 가져옵니다. 이미 펌웨어를 한 번 생성한 경우 이전 프로젝트에서 "继承"(계승) 버튼을 클릭할 수 있으며, 이는 매개변수 구성 단계를 절약해 줍니다.

![13](../../en/04-custom-protocol/images/13.png)

펌웨어를 다시 생성한 후 음성 상호작용 모듈에 펌웨어를 플래싱해야 합니다. 그러면 수정된 기능 항목이 활성화됩니다.

# 3. 새 명령 항목 추가

첨부 파일에서 "命令词播报词协议列表V1\_中文"(명령어/방송어 프로토콜 목록 V1\_중국어) 파일을 엽니다.

![14](../../en/04-custom-protocol/images/14.png)

스프레드시트 하단에 새 명령 항목을 추가합니다. 여기서는 "打扫房间"(방 청소) 명령어를 추가하는 것을 예로 듭니다.

![17](../../en/04-custom-protocol/images/17.png)

여기서 기능 유형으로 "命令词"(명령어)를 선택하고 방송 모드를 "主"(능동)로 설정해야 합니다. 이렇게 하면 "打扫房间"을 인식한 후 "好的"(알겠습니다)를 능동적으로 재생합니다.

![18](../../en/04-custom-protocol/images/18.png)

이제 송신 프로토콜을 살펴보겠습니다. 데이터의 1번째와 2번째 바이트는 데이터 프레임 헤더이며 수정할 필요가 없습니다. 기능 유형을 명령어로 선택하면 송신 프로토콜에 따라 3번째 데이터 바이트가 "00"이어야 합니다. 이는 명령이 "명령어"인지 "방송어"인지를 구분하기 위한 것입니다.

![19](../../en/04-custom-protocol/images/19.png)

4번째 데이터 바이트는 명령어의 데이터 ID이며 16진수 값입니다. 이전 명령어의 ID가 "8B"였으므로 이 바이트를 "8C"로 설정해야 합니다. 특수한 경우, 예를 들어 두 명령어가 반환하는 결과가 동일할 때는 데이터 ID가 같을 수 있습니다.

![20](../../en/04-custom-protocol/images/20.png)

프로토콜의 5번째 바이트는 "EE"로 고정되어 있으며 역시 수정할 필요가 없습니다. 스프레드시트에서 송신 프로토콜과 수신 프로토콜은 일치해야 합니다.

![21](../../en/04-custom-protocol/images/21.png)

수정 후 저장한 다음 "1.2 펌웨어 생성"의 단계에 따라 스프레드시트를 웹사이트로 가져옵니다. 이미 펌웨어를 한 번 생성한 경우 이전 프로젝트에서 "继承"(계승) 버튼을 클릭할 수 있으며, 이는 매개변수 구성 단계를 절약해 줍니다.

![13](../../en/04-custom-protocol/images/13.png)

펌웨어를 다시 생성한 후 음성 상호작용 모듈에 펌웨어를 플래싱해야 합니다. 그러면 새 명령 항목 기능이 활성화됩니다.

![14](../../en/04-custom-protocol/images/14.png)

스프레드시트 하단에 새 항목을 추가합니다. 여기서는 "现在是晚上"(지금은 저녁입니다) 방송어를 추가하는 것을 예로 듭니다.

![22](../../en/04-custom-protocol/images/22.png)
