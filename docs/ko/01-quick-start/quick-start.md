# 빠른 시작

출하 시 펌웨어에는 음성 인식 기능이 이미 포함되어 있으므로, 펌웨어를 플래싱하지 않고도 바로 체험할 수 있습니다. 인식 항목을 추가로 넣거나, 다른 펌웨어를 다시 플래싱하거나, 항목을 사용자 정의하려면 "3. 사용자 정의 프로토콜 항목 생성" 튜토리얼에서 항목을 사용자 정의하는 방법을 확인하십시오.

# 1. 준비

1. Type-C 데이터 케이블 1개
2. 음성 상호작용 모듈

# 3. 음성 인식 및 방송

Type-C로 음성 상호작용 모듈에 전원을 공급한 후, "你好，小犀"(안녕, 샤오시)라고 말하면 모듈이 깨어납니다. 깨우기에 성공하면 모듈이 "我在"(여기 있습니다)라고 응답하며, 현재 음성 인식 가능한 상태임을 나타냅니다. 15초 이내에 인식되는 명령 항목이 없으면 모듈은 휴면 모드로 진입하면서 "我去休息了"(저는 쉬러 갑니다)를 방송합니다. 모듈을 다시 깨우려면 웨이크 워드를 다시 말하면 됩니다.

출하 시 펌웨어에는 명령어와 방송어가 내장되어 있습니다. 제공되는 자료 첨부 파일에서 프로토콜 목록을 확인할 수 있습니다. 아래 표는 명령어 및 방송어 프로토콜 목록의 일부를 발췌한 것입니다. 기능 유형을 통해 각 명령어가 어떤 기능을 나타내는지 확인할 수 있습니다. 방송해야 하는 방송어 중 수동인 방송어는 PC 시리얼 포트나 기타 마이크로컨트롤러 또는 호스트 장치를 통해 음성 상호작용 모듈로 해당 명령을 전송해야 트리거됩니다. 자세한 내용은 아래를 참조하십시오.

방송 모드에는 능동과 수동 두 가지가 있습니다.

능동 방송: 표에 따라 명령어를 말하면 모듈이 해당 문구를 능동적으로 재생합니다. 깨운 후 "小车前进"(차량 전진)이라고 말하면 모듈이 "好的，正在前进"(알겠습니다, 전진 중입니다)을 능동적으로 방송합니다.

수동 방송: 프로토콜 표의 명령을 시리얼 포트를 통해 음성 모듈로 전송해야 모듈이 해당 문구를 재생합니다. IIC 프로토콜을 통해 수동 방송 레지스터에 해당 방송 데이터를 기록하여 트리거할 수도 있습니다. 자세한 내용은 "3. 다중 호스트 통신"을 참조하십시오.
