# 模块固件烧录方法

# 1.语音芯片烧录步骤

# 1.1设备连接

![1](../../en/05-firmware-flashing/images/1.png)

# 1.2.打开烧录软件

打开附件中的语音芯片固件烧录工具文件夹点击”PACK\_UPDATE\_TOOL.exe“

![2](../../en/05-firmware-flashing/images/2.png)

选择CI1302芯片，然后点击“固件升级”

![3](../../en/05-firmware-flashing/images/3.png)

进入固件升级界面，按下"F1"可查看帮助

点击选择 刚刚制作固 件 ， 找 到 附件中出厂固件 的 “ CI1302中文单麦\_V00681\_UART1\_115200\_2M”固件。

![4](../../en/05-firmware-flashing/images/4.png)

选择固件，找到对应的串口号，并点击方框打勾

![5](../../en/05-firmware-flashing/images/5.png)

将滑动开关拨到Download的位置，Download表示为语音芯片烧录固件（也就是靠右的一边）

![6](../../en/05-firmware-flashing/images/6.png)

拨到对应的位置之后，按下语音交互模块上的 RST 键，即可进入到烧录中，等待烧录成功，点击“退出”即可。

![7](../../en/05-firmware-flashing/images/7.png)
