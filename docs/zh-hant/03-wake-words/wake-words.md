# 修改喚醒詞與命令詞

# 1.注意事項

請在安靜的場景下進行修改喚醒詞，吵雜的環境會影響語音互動模組的辨識準確率。
說詞條時，聲音要宏亮且語速不宜過快，建議與模組之間保持在 5 米以內。

# 3.修改喚醒詞

對語音互動模組說出 “你好，小犀” 將語音互動模組喚醒，當模組回覆 “我在”時，表明當前處於可辨識狀態 
再對語音互動模組說出 “学习唤醒词”詞條，語音互動模組回應 “说出唤醒词”，即可進入到喚醒詞學習功能狀態 
接著對語音互動模組說出想要設定的喚醒詞，喚醒詞盡量簡短，這裡以設定 “你好，小犀”為例 
當語音互動模組辨識成功後，將會播報“学习成功”，表明喚醒詞修改成功，這時候我們就可以使用“你好小犀”詞條就能喚醒模組了。

注意事項：出廠韌體中的喚醒詞 “你好，小犀” 是基礎喚醒詞，無法透過語音進行修改或刪除。使用者使用語音修改的喚醒詞只能同時存在一個，與基礎喚醒詞時共同存在的。

# 4.修改命令詞

語音互動模組出廠韌體中預置 8個可以語音修改的命令詞，如下所示：

| 新增行 刪除選中 |              |                      |                                       |                  |
| --------------- | ------------ | -------------------- | ------------------------------------- | ---------------- |
|                 | * ☑ 語義標籤 | * ☑ 學習指令         | * ☑ 學習提示                          | * ☑ 刪除指令     |
|                 | 3            | 学习唤醒词           | 请在安静环境下，说出你要学 习的唤醒词 | 删除唤醒词       |
|                 | 11           | 学习小车停止指令     | 请说小车停止的指令                    | 删除小车停止指令 |
|                 | 12           | 学习停车指令         | 请说停车的指令                        | 删除停车指令     |
|                 | 13           | 学习小车休眠指令     | 请说小车休眠的指令                    | 删除小车休眠指令 |
|                 | 15           | 学习小车后退指令     | 请说小车后退的指令                    | 删除小车后退指令 |
|                 | 29           | 学习导航去一号位指令 | 请说出一号位指令                      | 删除一号位指令   |
|                 | 30           | 学习导航去二号位指令 | 请说出二号位指令                      | 删除二号位指令   |
|                 | 31           | 学习导航去三号位指令 | 请说出三号位指令                      | 删除三号位指令   |
|                 | 32           | 学习导航去四号位指令 | 请说出四号位指令                      | 删除四号位指令   |

用法舉例如下：

對語音互動模組說出 "你好，小犀"將語音互動模組喚醒，當模組回覆 “我在”時，表明當前處於可辨識狀態 
再對語音互動模組說出 “学习停车指令”詞條，語音互動模組回應 “请说指令”，即可進入到命令詞學習功能狀態 
接著對語音互動模組說出想要設定的命令詞，命令詞應該盡量簡短，這裡以設定 “前方停车”位置 
當語音互動模組辨識成功之後，會播報 “学习成功”，表明命令詞修改成功，這時候我們可以使用“前方停车” 詞條就能達到與 “停车”命令詞一樣的效果了 
如果需要刪除掉 ”前方停车“ 詞條，只需要說出 ”删除停车指令“ ，當回覆 ”删除成功”時，即可完成詞條刪除（這裡只會刪除“前方停车”，不會刪除 ”停车“）。

注意：出廠韌體中命令詞時基礎命令詞，無法透過語音進行修改或者刪除，使用者使用語音修改的命令詞只能同時存在一個，並且與基本命令詞共存。
