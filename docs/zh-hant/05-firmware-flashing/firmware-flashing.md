# 模組韌體燒錄方法

# 1.語音晶片燒錄步驟

# 1.1裝置連接

![1](../../en/05-firmware-flashing/images/1.png)

# 1.2.打開燒錄軟體

打開附件中的語音晶片韌體燒錄工具資料夾點擊”PACK\_UPDATE\_TOOL.exe“

![2](../../en/05-firmware-flashing/images/2.png)

選擇CI1302晶片，然後點擊“韌體升級”

![3](../../en/05-firmware-flashing/images/3.png)

進入韌體升級介面，按下"F1"可查看說明

點擊選擇 剛剛製作韌 體 ， 找 到 附件中出廠韌體 的 “ CI1302中文单麦\_V00681\_UART1\_115200\_2M”韌體。

![4](../../en/05-firmware-flashing/images/4.png)

選擇韌體，找到對應的序列埠號，並點擊方框打勾

![5](../../en/05-firmware-flashing/images/5.png)

將滑動開關撥到Download的位置，Download表示為語音晶片燒錄韌體（也就是靠右的一邊）

![6](../../en/05-firmware-flashing/images/6.png)

撥到對應的位置之後，按下語音互動模組上的 RST 鍵，即可進入到燒錄中，等待燒錄成功，點擊“退出”即可。

![7](../../en/05-firmware-flashing/images/7.png)
