# 產品資料

## 1.語音互動模組介紹

CI1302 是啟英泰倫研發的新一代高效能神經網路智慧語音晶片，整合了啟英泰倫自研的腦神經網路處理器BNPU V3 和 CPU核心，系統主頻可達 220MHz，內建高達 640KByte的 SRAM，整合 PMU 電源管理單元和 RC 振盪器，整合雙通道高效能低功耗 Audio Codec 和多路 UART、IIC、IIS、PWM、GPIO、PDM 等周邊控制介面。晶片僅需少量電阻電容等周邊元件就可以實現各類智慧語音產品硬體方案，性價比極高。

採用 3 代硬體 BNPU 技術，支援 DNN\TDNN\RNN\CNN 等神經網路及並行向量運算，可實現語音辨識、聲紋辨識、命令詞自學習、語音偵測及深度學習降噪等功能。該晶片方案還支援漢語、英語、日語等多種全球語言，可廣泛應用於家電、照明、玩具、穿戴式裝置、工業、汽車等產品領域，實現語音互動及控制和各類智慧語音方案應用。

CI1302 晶片具有腦神經網路處理器核心(BNPU)，支援離線 NN 加速運算和語音訊號處理硬體加速等，CPU 主頻可達 220MHz，能夠離線遠場語音辨識，內建 2MB FLASH 儲存，可支援 300 條命令詞。

## 2.產品特點

- 預設110+條語音指令，支援自訂中文和英文指令詞。

使用者可透過我們提供的網頁修改指令字，生成新的韌體檔案，並透過PC軟體將韌體寫入模組，模組即可辨識新指令。內建2M儲存空間，最多可寫入約120條指令字。

- 內建高傳真揚聲器和高效能麥克風。

它整合了先進的演算法和電路降噪技術，能夠有效過濾環境背景噪音，在5米範圍內辨識率可達99%，從而實現自然對話和回音消除。它能夠提供清晰的音質輸出，並準確還原語音細節。

- 板載協處理器和 IIC/序列埠/Type-C 介面。

它整合了STC8H晶片，可自動將語音資料轉換為序列埠或IIC資料格式，簡化了與外部主控裝置的通訊過程。免費提供多種連接線，使用者可以將其連接到MCU開發板和嵌入式主控裝置，實現通訊並建立自己的DIY專案。

- 提供基於各種開發板的使用教學

提供開發板資訊，例如 STM32、ESP32、MSPM0、Raspberry Pi、Jetson 系列開發板、RDK 等。並提供 ROS1 和 ROS2 系統的 SDK 檔案。

## 3.工作原理

該模組採取口令模式喚醒，使用者需要說出設定好的喚醒詞先啟用語音互動模組，啟用後之後就可以進行語音辨識，出廠韌體預設喚醒關鍵詞是 “你好，小犀”，如果15秒之後沒有辨識到語音，模組會進入休眠模式，再次使用的時候需要重新喚醒。

當CI1302晶片辨識到對應的語音詞條之後，會透過序列埠、IIC介面發送出去，並回饋播報；IIC晶片將接收到的語音指令儲存並透過IIC從機協定發送出來。

模組支援喚醒詞修改，命令詞修改和自訂詞條，可以在教學《修改喚醒詞和命令詞》，《自訂協定詞條製作》教學學習如何操作。

## 4.注意事項

1、使用5v電壓供電，超過5v會損壞模組

2、使用場景應該安靜，吵雜的環境會影響辨識效果

3、說詞條的時候，聲音要宏亮而且語速不宜過快，建議與模組之間保持在5米之內
