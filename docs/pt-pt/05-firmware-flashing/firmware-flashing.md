# 1.2 Abra o Software de Gravação

Abra a pasta da ferramenta de gravação de firmware do chip de voz nos anexos e clique em "PACK\_UPDATE\_TOOL.exe"

![2](../../en/05-firmware-flashing/images/2.png)

Selecione o chip CI1302 e, em seguida, clique em "固件升级" (Atualização de Firmware)

![3](../../en/05-firmware-flashing/images/3.png)

Entre na interface de atualização de firmware. Prima "F1" para ver a ajuda.

Clique para selecionar o firmware que acabou de criar. Encontre o firmware de fábrica "CI1302中文单麦\_V00681\_UART1\_115200\_2M" nos anexos.

![4](../../en/05-firmware-flashing/images/4.png)

Selecione o firmware, encontre o número da porta série correspondente e marque a caixa de verificação.

![5](../../en/05-firmware-flashing/images/5.png)

Mova o interruptor deslizante para a posição "Download". "Download" indica a gravação de firmware para o chip de voz (ou seja, o lado direito).

![6](../../en/05-firmware-flashing/images/6.png)

Após mover o interruptor para a posição correspondente, prima o botão RST no módulo de interação por voz para entrar no processo de gravação. Aguarde que a gravação termine com sucesso e, em seguida, clique em "退出" (Sair).
